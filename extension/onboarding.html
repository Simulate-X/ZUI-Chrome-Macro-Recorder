Local-first browser automation

Welcome to ZUI Macro Recorder for Chrome

Record a tab, review every event, then replay it without moving your real Windows mouse or keyboard.

  1. Select a Chrome tabOpen the extension and choose the tab you want to control. The first time you select a site, Chrome may ask you to allow ZUI access to that site.
  2. Record your actionsPress Record, use the page, then press Stop.
  3. Review the macroName it, edit delays or events, and save the validated result.
  4. Replay or move itPlay it on a newly selected target, or export it to another Chrome profile.

Why Chrome shows a debugging notice

ZUI uses Chrome’s debugging interface only for keyboard, text, select and wheel input on the tab you explicitly select. It does not control Windows input and does not export passwords, cookies or account credentials.
