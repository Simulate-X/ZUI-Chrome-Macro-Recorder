ZUI Macro Recorder

Settings

Global defaults apply first. A macro’s saved playback defaults override them; current-session changes win last.

Recording

Mouse mode

Playback

A repeat count of 0 means infinite. Use Stop or the Stop shortcut to end an infinite macro.

Shortcuts

Chrome may leave some extension shortcuts unassigned. You can set the recommended Jitbit-style shortcuts manually from Chrome’s extension shortcut settings.

Diagnostics

Reports are bounded and redact typed text, passwords, tokens, cookies and account data.

Data management

Library backups contain portable macros only. They never include tab, window, profile, account, cookie, token or runtime state.

Site access

Sites ZUI can access

ZUI asks for access only when you select a site. Access stays in this Chrome profile and is never included in macros or library backups.

Security and limits

ZUI uses Chrome’s debugging interface only to send keyboard, text, select and wheel input to the tab you explicitly select. It does not control the Windows mouse or keyboard. Sensitive fields are blocked. Cross-origin and closed Shadow DOM targets remain unsupported.
