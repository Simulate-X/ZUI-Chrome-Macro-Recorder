# Security and privacy reporting

ZUI Macro Recorder for Chrome handles recorded browser interactions, so reports must avoid exposing user data.

Do not post real macro exports, passwords, OTP values, cookies, access tokens, account details, browser profiles, personal screenshots, or unredacted diagnostics in a public issue. Reproduce with a synthetic local page and include only the stable technical error code when possible.

For a vulnerability or privacy issue that cannot be described safely in public, use GitHub Private Vulnerability Reporting if it is enabled for the repository. No private email address is published by this project. If private reporting is unavailable, open a minimal public issue that contains no exploit details or private data and ask the maintainers to provide a private channel.

The supported security surface is the current repository version. Reports should include the extension version and Chrome version, but not a user profile or browsing history.
